## The code, and why one resolves nowhere

A code is three parts: `<group>/<session>/<id>`. It resolves against *this* machine's
copy of the shared folder, so the two usual failures are a folder that hasn't finished
syncing and a colleague whose Kit files into a different group — neither of them a
problem with the code itself. What `where` reports shows both.

Anyone who can open that folder can open every handoff in it. There is no per-handoff
permission and nothing to grant; sharing the folder shared all of it. Say so if someone
asks whether a particular handoff was visible to a particular person.
