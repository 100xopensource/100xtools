## The code, and why one resolves nowhere

A code resolves through the sending team's own server, which decides who may read what.
A refusal there is an access decision, not a missing handoff: the person who sent it has
to grant it, and there is no other route to try.

A code that resolves for the sender and not for you is therefore normal and fixable —
one message to them. A code that resolves for nobody is usually from a different team's
setup entirely.
