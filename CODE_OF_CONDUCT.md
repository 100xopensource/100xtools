# Code of Conduct

## Our pledge

We want this project to be a straightforward place to contribute. Everyone participating —
maintainers, contributors, people filing issues — is expected to treat others with respect,
regardless of experience, background, or identity.

## Expected behaviour

- Be direct about code and gentle about people. Critique the change, not the author.
- Assume the other person had a reason. Ask what it was before concluding they were careless.
- Accept that maintainers may decline a change that is well made but out of scope, and say
  so plainly rather than letting a PR go stale.

## Unacceptable behaviour

Harassment, personal attacks, demeaning comments, publishing others' private information,
and sustained disruption of discussion.

## Reporting

Report a problem to the maintainers via
[private vulnerability reporting](https://github.com/100xopensource/100xtools/security/advisories/new)
or by contacting the repository owners directly on GitHub. Reports are handled
confidentially. Maintainers will respond with whatever action is warranted, from a private
word to a ban.
